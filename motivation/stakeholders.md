# Стейкхолдеры Git Herder

Реестр [стейкхолдеров][STAKEHOLDER-TERM] продукта. В реквестах и capability
указывать **только ссылками** на ID из этой таблицы.

| ID | Роль | Интерес |
| -- | ---- | ------- |
| **ST-1** | Разработчик в мультирепозиторной системе | Быстро получить и поддерживать актуальный набор рабочих копий; переключить ветки и публиковать связанные изменения без пропусков репозиториев |
| **ST-2** | Тимлид | Онбординг в проект; контроль состояния множества репозиториев на SCM; единообразие интеграций и метаданных на платформе |
| **ST-3** | Maintainer OSS Git Herder | Предсказуемый CLI, расширяемость на несколько SCM-платформ, низкий порог входа для контрибьюторов и пользователей |
